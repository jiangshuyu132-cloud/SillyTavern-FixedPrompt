# 固定提示词 · SillyTavern 扩展

写一次，每次聊天自动带给 AI。深色与金色的悬浮面板，无需额外服务、API 密钥或构建步骤。

## 安装

酒馆 → 扩展程序 → 安装扩展 → 粘贴以下地址：

```text
https://github.com/jiangshuyu132-cloud/SillyTavern-FixedPrompt
```

分支留空，点击「只给我安装」，安装完成后刷新酒馆。

## 使用

1. 点击聊天正文左侧贴边的金色长条，面板会通过金色粒子动画缓慢展开成正方形（4.5 秒）。
2. 填写固定提示词，保持「启用固定提示词」勾选。修改会自动保存到酒馆当前账号的扩展设置中，并在下一次生成生效。
3. 「高级设置」默认收起，点击后通过粒子动画向下展开（3.5 秒），可调整发送身份和插入深度；再次点击收起（0.9 秒）。屏幕较小时可在面板内滚动查看下方设置。
4. 点击右上角收起按钮或再次点击金色长条，关闭面板。关闭界面不会关闭提示词功能；下次打开时高级设置重新收起。

界面会随聊天正文位置与屏幕宽度调整。系统开启「减少动态效果」时直接展开和收起。插件样式与酒馆主题隔离，保持附件确认的深色与金色外观。

初次安装内容为空，不会擅自添加任何规则。开关关闭时保留内容，清空内容时停止注入。更新扩展不覆盖已保存的提示词。

## 生效方式

- 作用于当前酒馆账号的所有角色、单聊和群聊。
- 普通聊天、重新生成、滑动生成其他回复、继续回复都会携带。
- 同一次提示词组装中只保留一份，不会随聊天轮数叠加。
- 使用酒馆原生 `setExtensionPrompt` 接口，在发送给模型的上下文中注入；不增加聊天楼层，不修改用户原消息。
- 默认身份为系统提示，默认深度为 0（最近一条聊天之后）；高级设置可改为用户或助手身份，并调整深度。
- 支持酒馆原生宏，例如 `{{user}}`、`{{char}}`，由酒馆在组装请求时解析。
- 后台静默生成（如部分总结插件）和 AI 代写用户消息时不注入。直接调用无聊天上下文的 `generateRaw` 不在本扩展范围内。
- 提示词会占用模型上下文和 token。模型对提示词的执行仍受其能力、其他上下文和服务规则影响。

## 发送检查（1.1.1）

填写后显示「等待下一次发送检查」。正常发送或重新生成后，面板及「高级设置 → 发送检查」会显示本次结果：

- **已找到**：在酒馆待发送给后端的请求中匹配到了当前提示词。
- **已补回**：待发送请求中原本缺失，已按深度 0 和所选身份补入一次。
- **未找到 / 未核验**：显示具体原因，不把保存成功当作发送成功。

1.1.1 修复了一个可复现的漏带场景：其他扩展在正常生成过程中插入后台生成时，共用的原生提示词位置可能被清空。新版在 Chat Completion 的 `CHAT_COMPLETION_SETTINGS_READY` 事件中，按请求自身的生成类型再次检查，避免以最近一次后台任务的类型误判正常聊天。

检查适用于 Chat Completion（包括自定义兼容接口）。缺失补回仅用于深度 0、纯文本和 `{{user}}` / `{{char}}` 提示词；非零深度、工具调用请求只报告缺失，避免改动配置的位置或工具顺序。动态宏继续走原生注入，不重复求值，不声称已自动核验。其他 API 保留原生注入，若未取得检查事件则显示未核验。

检查只读取当前请求的文字，不记录或上传请求、聊天或检查报告。补回内容仍占用上下文和 token；结果表示酒馆发送前这一阶段的情况，不能证明后端、中转服务或模型最终接收、执行了提示词。已有聊天回复不会随设置修改而改变。

## 数据

扩展本身不向第三方服务器发起网络请求。提示词由酒馆保存，生成时随酒馆请求发给你配置的模型服务。公开仓库只有插件程序和文档，不包含你填写的提示词或聊天记录。

## 维护

在酒馆「管理扩展」中更新本扩展，然后刷新页面。新版直接读取旧版保存的提示词、启用状态、身份和深度，无需重新填写。停用或卸载后刷新页面；支持生命周期钩子的酒馆版本还会立即移除悬浮面板、本扩展注册的提示词和事件监听。

开发测试：使用 Node.js 22 或更新版本，运行 `npm install` 后运行 `npm test`（或使用 `pnpm install --frozen-lockfile && pnpm test`）。测试覆盖提示词注入、旧设置恢复、真实控件保存、两级动画时序、中途收起、缩小窗口、减少动态效果和停用清理。DOM 测试使用模拟尺寸，不代替浏览器视觉验收。

从仓库根目录启动本地静态服务器后，打开 `tests/browser.html`，可在独立的示例聊天中检查实际动画、滚动和移动端布局；不连接酒馆账号或模型服务。插件用户不需要安装开发依赖。

接口参考：[酒馆官方扩展开发文档](https://docs.sillytavern.app/for-contributors/writing-extensions/)。
