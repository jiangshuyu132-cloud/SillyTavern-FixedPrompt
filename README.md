# 固定提示词 · SillyTavern 扩展

写一次，每次聊天自动带给 AI。中文设置界面，无需额外服务、API 密钥或构建步骤。

## 安装

酒馆 → 扩展程序 → 安装扩展 → 粘贴以下地址：

```text
https://github.com/jiangshuyu132-cloud/SillyTavern-FixedPrompt
```

分支留空，点击「只给我安装」，安装完成后刷新酒馆。

## 使用

1. 打开酒馆「扩展程序」面板，展开「固定提示词」。
2. 填写固定提示词，保持「启用固定提示词」勾选。
3. 正常发送聊天。修改会自动保存到酒馆当前账号的扩展设置中，并在下一次生成生效。

初次安装内容为空，不会擅自添加任何规则。开关关闭时保留内容，清空内容时停止注入。更新扩展不覆盖已保存的提示词。

## 生效方式

- 作用于当前酒馆账号的所有角色、单聊和群聊。
- 普通聊天、重新生成、滑动生成其他回复、继续回复都会携带。
- 同一次提示词组装中只保留一份，不会随聊天轮数叠加。
- 使用酒馆原生 `setExtensionPrompt` 接口，在发送给模型的上下文中注入；不增加聊天楼层，不修改用户原消息。
- 默认身份为系统提示，默认深度为 0（最近一条聊天之后）；高级设置可改为用户提示或调整深度。
- 支持酒馆原生宏，例如 `{{user}}`、`{{char}}`，由酒馆在组装请求时解析。
- 后台静默生成（如部分总结插件）和 AI 代写用户消息时不注入。直接调用无聊天上下文的 `generateRaw` 不在本扩展范围内。
- 提示词会占用模型上下文和 token。模型对提示词的执行仍受其能力、其他上下文和服务规则影响。

可用一段容易辨认的普通文字测试，并在酒馆的提示词查看功能中搜索该文字。这里的启用状态表示插件已配置好注入，不代表远端模型已经接收或执行。

## 数据

扩展本身不向第三方服务器发起网络请求。提示词由酒馆保存，生成时随酒馆请求发给你配置的模型服务。公开仓库只有插件程序和文档，不包含你填写的提示词或聊天记录。

## 维护

在酒馆「管理扩展」中更新本扩展。停用或卸载后刷新页面；支持生命周期钩子的酒馆版本还会立即移除本扩展注册的提示词和事件监听。

开发测试：Node.js 18+ 下运行 `npm test`，无需安装依赖。

接口参考：[酒馆官方扩展开发文档](https://docs.sillytavern.app/for-contributors/writing-extensions/)。
