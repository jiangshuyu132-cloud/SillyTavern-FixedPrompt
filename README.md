# 固定提示词 · SillyTavern 扩展

写一次，每次聊天自动附在本次用户消息后面，一起发给 AI。深色与金色的悬浮面板，无需额外服务、API 密钥或构建步骤。

## 安装与更新

酒馆 → 扩展程序 → 安装扩展 → 粘贴以下地址：

```text
https://github.com/jiangshuyu132-cloud/SillyTavern-FixedPrompt
```

分支留空，点击「只给我安装」，安装完成后刷新酒馆。

已经安装：在酒馆「管理扩展」中找到「固定提示词」，点击更新，再刷新页面。高级设置显示 **v1.2.3** 即为新版，无需重新填写提示词。

1.2.3 修复粒子动画残留金色竖杠：每帧按实际画布像素完整清除，动画结束或取消时重置并隐藏画布；绘制中断时清理残影、恢复控件，本页面后续改用无动画展开。修正页面缩放时粒子边缘坐标，保留正常情况下的展开、消散效果和时长。更新后请刷新，让已加载的旧画布一并移除。

1.2.2 是稳定性更新：修复短消息误匹配预设、图片消息重复附带、空白与回车处理导致误报、重复处理同一消息副本时叠加提示词，以及只读请求误报；文本补全核对会排在已注册的其他请求处理器之后。浏览器拒绝 Canvas 绘图时自动跳过动画，仍可编辑、保存和附带提示词。保留已确认的界面、动画和原有设置。详见[稳定性检查记录](STABILITY-REVIEW.md)。

## 使用

1. 点击聊天正文左侧贴边的金色长条，面板通过金色粒子动画缓慢展开成正方形（4.5 秒）。
2. 填写固定提示词，保持「启用固定提示词」勾选。修改自动保存到酒馆当前账号，并在下一次组合请求时生效。
3. 「高级设置」默认收起，点击后通过粒子动画向下展开（3.5 秒），可查看「本次发送内容」并一键复制；再次点击后通过不规则粒子消散收起（按附件为 2.87 秒）。屏幕较小时可在面板内滚动查看。
4. 点击右上角「收起」或再次点击金色长条，整块面板在 3.5 秒内不规则消散，残余粒子随后自然散尽。关闭界面不会关闭自动附带；下次打开时高级设置重新收起。

1.2.1 接入「粒子展开与不规则消散-3.5秒」附件的关闭效果：内部一处、左右边缘各一处同时开始，沿随机、局部快慢不同的边缘撕裂，产生金色微粒、发光边缘和细小碎片。保留原有展开动画，以及 1.2.0 的发送、保存和复制功能。展开未完成时再次点击长条会取消展开；消散中重复点击不会重启动画。

界面随聊天正文位置与屏幕宽度调整。系统开启「减少动态效果」时直接展开和收起。插件样式与酒馆主题隔离，保持附件确认的深色与金色外观。

初次安装内容为空，不会擅自添加任何规则。开关关闭时保留内容，清空内容时停止附带。更新扩展不覆盖已保存的提示词。

## 发送方式

普通发送、重新生成、滑动生成其他回复、继续回复时，插件在本轮聊天副本中找到最近一条用户消息，在末尾附上固定文本。发送给模型的**同一条用户消息**包含两部分，例如：

```text
带我去城门。

【固定提示词】
请用简体中文回复。
```

- 作用于当前酒馆账号的所有角色、单聊和群聊。
- 在上下文 token 预算计算之前组合内容；固定文本占用上下文和 token。
- 不新增聊天楼层，不修改保存的聊天记录。新一轮从原始聊天重新组合，避免历史层层累积固定文本。
- 没有用户消息的首次生成，会在本轮请求中创建一条临时用户消息。
- 支持酒馆宏，例如 {{user}}、{{char}}。每轮组合时解析一次，之后的发送前检查复用同一结果。已开始组合的请求保留当时的文本；编辑应用到下一次组合。
- 后台静默生成（如部分总结插件）和 AI 代写用户消息时不附带。直接调用无聊天上下文的 generateRaw 不在本扩展范围内。

1.2.0 将发送方式改为「本次用户消息＋固定提示词」，移除了身份和深度控件。以前保存的固定文本和启用状态继续使用；旧身份、深度数值仍保留在设置中，但不参与新的发送方式。旧版独立注入会被清理，避免同一扩展同时附带两份。

## 本次发送内容与一键复制

发送后打开「高级设置 → 本次发送内容」：

- **已组合**：已修改生成副本，等待发送前核对。预览为组合后的用户消息。
- **已附带**：在待发送请求中核对了本次用户消息及固定文本。Chat Completion 预览直接读取该请求中的用户消息文字。
- **未附带 / 未核验**：显示具体原因，不把保存成功或历史里出现过相同文字当作本轮附带成功。

「一键复制」复制预览中的完整文字。图片和音频等附件仍保留在原请求中，预览和复制只包含文字。使用 HTTP 地址的酒馆也会尝试浏览器兼容复制方式；浏览器拒绝时可手动选择预览文字复制。

Chat Completion 通过酒馆的发送前事件核对；若其他扩展移除了固定文本但保留了可识别的本次用户原文，会在同一条用户消息中补回。无法找到本次用户消息时显示「未核验」，避免把不确定当作成功或把提示词补到无关消息。文本补全接口在聊天副本中完成附带，通过最终文本核对；无法取得或匹配最终文本时显示未核验，不盲目补到模型回复前缀后面。

状态表示酒馆发送前这一阶段的结果，不证明网络传输、中转服务或模型最终接收、执行情况。预览只保存在当前页面内存中，编辑提示词、切换聊天或刷新时清空，不写入聊天文件和插件设置。已有回复不会随设置修改而改变。

## 数据与停用

扩展本身不向第三方服务器发起网络请求。提示词由酒馆保存，生成时随酒馆请求发给你配置的模型服务。公开仓库只有插件程序和文档，不包含你填写的提示词或聊天记录。

停用或卸载后刷新页面；支持生命周期钩子的酒馆版本还会立即移除悬浮面板和本扩展的事件监听。

## 开发验证

使用 Node.js 22 或更新版本，运行 npm install 后运行 npm test（也可使用 pnpm）。1.2.3 共通过 72 项自动检查，其中一项包含连续 1,500 轮混合生成模拟。测试覆盖同一用户消息的序列化结果、重复生成去重、历史误匹配、宏求值、图片和音频保留、后台嵌套任务、旧设置恢复、复制、两级动画时序、消散遮罩、连续点击、动画中缩放、减少动态效果、绘图受限和停用清理；新增画布残留、缩放对齐、绘制中断恢复检查。DOM 测试使用模拟尺寸和 Canvas，不代替实际酒馆和浏览器验收。

从仓库根目录启动本地静态服务器后，打开 tests/browser.html，可在独立示例中查看动画、滚动、移动布局，并模拟发送以核对预览和复制；不连接酒馆账号或模型服务。插件用户不需要安装开发依赖。
